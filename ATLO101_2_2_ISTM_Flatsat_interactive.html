Interface Safe-to-Mate (Flatsat)

CSTM verifies the component. ISTM verifies the other half of the mate: the interface it's about to be connected to. This time, the component is a 3-phase reaction wheel motor.

CSTM vs. ISTM

A CSTM check verifies the component is healthy before it is mated — that's what you just did with the deployment initiator. An ISTM (Interface Safe-to-Mate) check verifies the other side of that same mate: the harness or interface the component is about to be connected to. You confirm the harness is wired to the correct far-end pins and is electrically clean — no shorts to structure, no shorts between conductors — before it is ever allowed near sensitive flight avionics.

What You're Verifying

This harness will carry the three motor-phase drive signals from the avionics box to a reaction wheel assembly (Lesson F.3, GNC). Reaction wheels use a 3-phase brushless DC motor wound in a "wye" configuration — three windings meeting at a common internal point that is not brought out to a pin. The values below are representative teaching figures, not a specific manufacturer's published spec — unlike the initiator exercise, real wheel-to-wheel winding resistance varies by design and is taken from that unit's own acceptance data.

The Balance Check — A New Technique

Every CSTM check so far has compared one measurement against one expected value. A 3-phase wye motor gives you a second technique: because all three windings are (by design) nominally identical, the phase-to-phase resistance between every pair — U-V, V-W, and U-W — should match each other, not just match a single spec number. A winding fault often shows up as one pair reading noticeably different from the other two, even when no single reading looks obviously wrong on its own.

Exercise — Predict and Check

Draft your answer, then reveal a model answer to self-check.
Before mating this harness, you will measure phase-to-phase resistance across all three winding pairs and insulation resistance from each phase to the case. Using Fig. 2.2-C, state what a healthy result looks like for each measurement, and what a result would need to look like to fail the check even if every individual number were "reasonable."
MODEL ANSWER

Phase-to-phase: All three pairs (U-V, V-W, U-W) should read approximately the same value — around 2.4 Ω each in this example, with only small run-to-run variation. A fail is not just a reading far from 2.4 Ω — it is any one pair reading meaningfully different from the other two, even if that reading alone would look plausible in isolation.

Insulation resistance: Each phase (U, V, W) measured to case should read ≥ 10 MΩ @ 500 VDC, with the harness fully de-energized. A low reading on any single phase indicates a winding-to-case insulation breakdown on that phase specifically.

  • Did you compare the three phase pairs to each other, not just to a single fixed number?
  • Did you specify de-energizing the harness before this check, same as any resistance measurement?

Scenario — An Unbalanced Reading

Read the three results together, then choose your assessment.
You measure U-V = 2.4 Ω, V-W = 2.4 Ω, and U-W = 0.2 Ω. Every individual number is a plausible-looking low resistance value. What is your assessment?

Real-World Grounding

The phase-balance technique itself is real, standard motor and generator maintenance practice — comparing multiple nominally-identical windings against each other, not just against a fixed number, catches faults a single-measurement check would miss. The measurement discipline (de-energize first, then measure resistance) is the same NEETS Module 3 ohmmeter principle from Lesson 2.1, applied here to a three-winding component instead of a two-terminal one.
